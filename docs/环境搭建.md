# 环境搭建

## 依赖

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`requirements.txt` 里三样：`openai`（调接口，走 OpenAI 兼容协议）、`rank-bm25`（关键词检索）、`streamlit`（界面，暂未用上）。

> 一定要用 `.venv\Scripts\python.exe` 显式指定解释器，不要靠"激活虚拟环境"。激活失败时 IDE 会静默回落到系统 python，报 `ModuleNotFoundError: No module named 'rank_bm25'`，看着像没装、其实装错了地方。

## pip 下载慢

国内默认源是 pypi.org，装 streamlit 会连带 pandas + pyarrow 约 80MB，第一次很慢。固定镜像一劳永逸：

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

写入 `%APPDATA%\pip\pip.ini`，对本机所有项目生效。

以后要装 `sentence-transformers` 这类带 torch（约 2GB）的包，单独装，别和别的混在一起：

```bash
.venv\Scripts\python.exe -m pip install sentence-transformers -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## run.bat 必须用 CRLF 换行

`.bat` 文件如果被存成 LF 换行，cmd 会把 `@echo off` 读成 `cho off`，报：

```
'cho' 不是内部或外部命令
```

改法：VSCode 右下角把 `LF` 切成 `CRLF` 保存。同时 `.bat` 内容只用 ASCII，中文注释在 GBK/UTF-8 混用时会乱码。
